# DEMO-SPEC

**Nicht deployen. Unsichtbar für den Kunden.** Diese Datei ist die verbindliche
Grundlage der ganzen Demo. Der `brief-analyst` füllt sie in Phase 0, nachdem
Bruno die Spec bestätigt hat.

Sie existiert, weil das Hauptziel sonst unterwegs verloren geht: In einer Demo
stand "starke Karriereseite" im Briefing und tauchte im fertigen Entwurf nicht
mehr auf, weil die Spec nur im Chat lebte. `structure-architect` und
`qa-reviewer` prüfen später ausdrücklich gegen diese Datei – **nicht nur, ob
eine Sektion existiert, sondern ob sie die Gewichtung hat, die hier steht.**
